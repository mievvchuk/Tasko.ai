## Як відтворити

1. Запустити PostgreSQL, створити окрему базу (напр. `taskoai_qa`), застосувати `npm run db:migrate` і `npm run seed:demo` з `DATABASE_URL` цієї бази.
2. Запустити API на цій базі без `AI_API_KEY` і сайт з `API_PROXY_TARGET` на нього.
3. HTTP-сценарії: скрипт `scenarios.mjs` (див. додаток в AUDIT_REPORT.md). Ліміт реєстрацій 10/15 хв з IP: негативні тести реєстрації запускати окремо після перезапуску API.
