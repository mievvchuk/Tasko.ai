# Діаграми Tasko.ai

Файли Mermaid відповідають фактичній реалізації застосунку. Їх можна відкрити у Mermaid Live Editor або переглянути в редакторі з підтримкою Mermaid.

| Файл | Тип діаграми |
| --- | --- |
| `use-case.mmd` | Use Case |
| `class.mmd` | Class |
| `component.mmd` | Component |
| `sequence-application.mmd` | Sequence |
| `state-project.mmd` | State |
| `activity-work.mmd` | Activity |
| `database.mmd` | Схема бази даних |
| `c4-context.mmd` | C4 Context |
| `deployment.mmd` | Deployment |

Deployment-діаграма показує логічні вузли системи без вибору хмарної платформи. Конкретний сервіс розгортання буде додано після окремого рішення.
