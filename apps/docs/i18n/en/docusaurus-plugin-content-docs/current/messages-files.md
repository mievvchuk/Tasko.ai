## Messages

[Messages](https://taskoai.pp.ua/messages) has two groups of conversations:

- **My projects** — the chat of all project members: the client and the team.
- **Applications** — messages between a client and an applicant before hiring. It appears as soon as one of them writes the first message.

New messages appear instantly, without reloading the page, and are duplicated in [notifications](./notifications-workload.md). The first page of history holds the newest messages, the next ones are older.

:::info
When a project is completed or cancelled, its chat stays readable. Likewise, application messages become read-only after the client's decision.
:::

## Files

**Files** are shared project documents (project page → **Files**).

- Formats: PDF, PNG, JPG, DOCX, ZIP or TXT (UTF-8).
- Size: up to **10 MB** per file.
- Project members can upload and delete files.
- Only project members can see the files.

You can also attach a file when [submitting work](./submit-work.md).
