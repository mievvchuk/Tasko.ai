## Reviewing applications

On the project page click **Applications**. Each application shows:

- the proposed **budget** and **timeline** in days;
- the **cover message** — how the freelancer plans to do the work;
- a name linking to the **profile**: skills, rate, portfolio, rating.

If there are many applications, ask [Ada](./ai.md) to rank them — she explains why she recommends each candidate.

## Messaging a candidate

If an application lacks details, click **Message the freelancer**. A separate chat about this application opens in [Messages](./messages-files.md) → **Applications**. New messages arrive instantly, without reloading the page.

The chat is visible only to you and the applicant and works while the application is **awaiting decision**. After the decision it stays read-only.

## Hiring a team

1. Click **Add to team** on an application that fits.
2. The freelancer joins the project and gets access to the board, milestones, chat and files.
3. The project becomes **In progress** but **stays on the marketplace** marked "Building a team", so you can hire more people.
4. Reject applications that don't fit with **Reject** — the applicant is notified.

## Closing hiring

When the team is complete, click **Close hiring**. The project leaves the marketplace, and all applications still awaiting a decision are rejected with a notification to their authors.

:::tip
Split tasks between members on the [board](./board.md): the **Assignee** filter shows who is busy with what.
:::
