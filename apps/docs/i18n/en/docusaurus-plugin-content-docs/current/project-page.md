The project page gathers everything about it. At the top are the title and action buttons, below are the sections.

## Overview

- **Description**, **status**, **deadline** and **budget**.
- **Freelancers** — how many people are in the team, and the member list.
- **Progress** — how many tasks out of the total are done.
- **Project tasks** — a list with search, filters by status, priority and assignee, and an "Overdue only" toggle.

## Sections

| Section | What's there |
|---|---|
| **All tasks** | This project's tasks on the [Tasks](./board.md) page |
| **Messages** | The chat of project members, see [Messages and files](./messages-files.md) |
| **Files** | Shared documents |
| **Kanban** | The board with columns, see [Kanban board](./board.md) |
| **Milestones** | Large parts of the work, see [Milestones](./milestones.md) |
| **History** | Who changed what in the project and when |
| **AI analysis** | Ada assesses the project's risks and progress, see [AI assistant](./ai.md) |
| **AI planning** | A draft of milestones and tasks from the description (owner only) |

## Client actions

The project owner sees **Edit project**, **Create task** and **Applications**. Editing lets you change the terms and the status: pause, complete or cancel the project.

When the project is **Completed**, a **review** form appears in the member list: a rating from 1 to 5 and a comment. Reviews make up the freelancer's rating.

## Freelancer actions

A team member sees the **Task queue** block with **Take the next task** — work gets distributed without manual assignment. See [Finding work and applying](./find-work.md#after-being-hired).
