# Дизайн-система Tasko.ai

Дизайн зроблено за правилами Hallmark (тема «Dose»): спокійний інтерфейс, один
зелений колір для дій і дві теми, біла та чорна. Логіку, маршрути й тексти
компонентів не змінено, змінено лише стилі.

## Три файли стилів

| Файл              | Що в ньому                                                            |
| ----------------- | --------------------------------------------------------------------- |
| `src/tokens.css`  | Усі кольори, шрифт, відступи, розміри тексту. Дві теми: біла й чорна. |
| `src/base.css`    | Скидання стилів браузера, заголовки, посилання, фокус, зменшений рух. |
| `src/app.css`     | Компоненти й сторінки. Імпортує два файли вище.                       |

`src/main.tsx` підключає лише `app.css`.

**Як пояснити:** компоненти ніколи не пишуть колір чи відступ числом, лише
змінною: `color: var(--color-ink)`, `padding: var(--space-md)`. Тому, щоб змінити
колір на всьому сайті, достатньо поправити одну змінну в `tokens.css`.

## Як працюють дві теми

`src/theme.ts` ставить на `<html>` атрибут `data-theme="light"` або `"dark"`.
У `tokens.css` блок `:root` задає світлі кольори, а блок `:root[data-theme="dark"]`
перевизначає ті самі змінні темними значеннями. Компоненти про тему нічого не знають.

Темна тема не просто інвертує світлу:

- фон майже чорний, але не `#000`; текст майже білий, але не `#fff`;
- картки світліші за фон (у світлій темі навпаки);
- тіней немає, спливні меню відділяє тонка рамка;
- зелений світліший і менш насичений, щоб не сліпив.

## Кольори

| Змінна                 | Для чого                                         |
| ---------------------- | ------------------------------------------------ |
| `--color-paper`        | фон сторінки                                     |
| `--color-paper-2`      | бічна панель, заголовки таблиць, сірі комірки    |
| `--color-paper-3`      | наведення, колонки Kanban, сірі пілюлі           |
| `--color-surface`      | картки й поля вводу                              |
| `--color-ink`          | основний текст                                   |
| `--color-ink-2`        | другорядний текст                                |
| `--color-muted`        | підписи й підказки                               |
| `--color-rule`         | тонкі лінії                                      |
| `--color-accent`       | зелена кнопка, вибране                           |
| `--color-accent-soft`  | м'ятний фон: активний пункт меню, «у роботі»     |
| `--color-error`        | помилки, прострочене, високий пріоритет          |

Кольори записано у форматі `oklch(світлість насиченість відтінок)`. Усі нейтральні
відтінки трохи зеленуваті (відтінок 160), тому сірий не здається «мертвим».

**Статуси:** сірий — не почато, м'ятний — у роботі, зелена рамка — на перевірці,
зелений — завершено, червоний — скасовано.

## Відступи й текст

- Відступи лише зі шкали: 2, 4, 8, 12, 16, 24, 40, 64, 96, 144 px (`--space-3xs` … `--space-4xl`).
- Розміри тексту за кроком 1.2 від 16px (`--text-xs` … `--text-3xl`).
- Один шрифт, Manrope (файл у `public/fonts`), три накреслення: 400, 600, 700.
- Підписи, заголовки таблиць і пункти меню пишуться звичайним регістром, без
  великих літер і розрядки.

## Компоненти

- **Кнопки** заввишки 40px. Залита лише одна, зелена `.primary`; решта з рамкою
  або текстові. Є всі стани: наведення, натискання, фокус і недоступна.
- **Поля** такої ж висоти, як кнопки. Фокус показано кільцем, рамка не стрибає.
- **Картки:** тонка рамка без тіні. Усередині картки немає інших карток, лише сірі комірки.
- **Показники на головній** стоять в одному ряду й розділені лініями.
- **Kanban:** колонки сірі, картки білі, колонка під карткою, яку тягнуть, стає м'ятною.

## Анімації

Лише CSS, розділ «15. Анімації» в `app.css`. Три заготовки `@keyframes`:
`fade-in` (поява), `pop-in` (поява з легким збільшенням) і `rise` (поява знизу).
Анімуються тільки `opacity` і `transform`, бо браузер малює їх плавно.

- Меню акаунта й мобільне меню з'являються за 220 мс.
- Діалог адмінки трохи збільшується до свого розміру, фон під ним темнішає.
- Повідомлення про успіх і помилки проявляються, а не вискакують.
- Нова відповідь AI-помічниці виїжджає знизу.
- На вітальній сторінці перший екран з'являється один раз, рядок за рядком.

Анімація запускається, коли React додає елемент на сторінку, тож JavaScript для
неї не потрібен. Тривалості беруться з токенів `--dur-short` і `--dur-long`.

## Навігація

- Від 960px: бічна панель з іконками й підписами. Тема, мова й акаунт унизу.
- До 960px: верхня панель і кнопка ☰.
- До 640px: ще й нижня панель із чотирма головними розділами.

## Доступність

- Фокус з клавіатури видно завжди, кільце з'являється одразу, без анімації.
- Контраст тексту відповідає WCAG AA в обох темах.
- `prefers-reduced-motion` вимикає всі анімації (`base.css`).

## Перевірка

```bash
node <hallmark>/scripts/sloplint.mjs apps/web/src --genre modern-minimal --scope app
```

Результат: 0 FAIL, 0 REFLEX. Рішення щодо решти попереджень записано на початку `app.css`.
