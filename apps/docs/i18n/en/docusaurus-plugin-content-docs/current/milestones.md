Milestones split a project into large parts with their own dates and amount, e.g. "Design", "Development", "Testing". Both the client and the team see what's done and what's next.

## Creating a milestone

1. On the project page open **Milestones**.
2. The client adds a milestone: **title**, **deadline**, **amount** in UAH.
3. Tasks are linked to a milestone in the task form — and its progress is visible at once.

## Milestone statuses

**Planned → In progress → In review → Completed**

## Payment marks

Tasko.ai does not process payments. So both sides see what was agreed, each milestone has a mark:

| Mark | Meaning |
|---|---|
| **Not reserved** | Payment hasn't been discussed yet |
| **Conditionally reserved** | The client confirmed the money for the milestone is set aside |
| **Marked as paid** | The client marked the milestone as paid outside the platform |

:::tip
Milestones can be generated automatically: open **AI planning** on the project page. See [Ada the AI assistant](./ai.md).
:::
