## Повідомлення

Розділ [Повідомлення](https://taskoai.pp.ua/messages) має дві групи розмов:

- **Мої проєкти** — чат усіх учасників проєкту: клієнта й команди.
- **Заявки** — переписка клієнта з автором заявки до найму. Вона з'являється, щойно хтось із двох напише перше повідомлення.

Нові повідомлення з'являються одразу, без оновлення сторінки, і дублюються в [сповіщеннях](./notifications-workload.md). Перша сторінка історії містить найновіші повідомлення, наступні — раніші.

:::info
Коли проєкт завершено або скасовано, його чат лишається доступним для читання. Так само переписка щодо заявки стає лише для читання після рішення клієнта.
:::

## Файли

**Файли** — спільні документи проєкту (сторінка проєкту → **Файли**).

- Формати: PDF, PNG, JPG, DOCX, ZIP або TXT (UTF-8).
- Розмір — до **10 МБ** на файл.
- Завантажувати й видаляти файли можуть учасники проєкту.
- Файли бачать лише учасники проєкту.

До [здачі роботи](./submit-work.md) теж можна додати файл.
