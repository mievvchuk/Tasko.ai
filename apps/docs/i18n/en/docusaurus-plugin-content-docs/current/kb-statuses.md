## Project

| Status | Meaning |
|---|---|
| **In moderation** | A new or changed project awaits an administrator's review. Only the owner sees it |
| **Rejected by moderator** | The project must be fixed according to the reason and saved again |
| **Looking for a freelancer** | On the marketplace, accepting applications |
| **In progress** | The team is hired and work is going on. Until hiring is closed, the project stays on the marketplace marked "Building a team" |
| **Paused** | Work is temporarily stopped |
| **Completed** | The work is accepted; reviews can be left |
| **Cancelled** | Closed without a result |

## Task

**To do → In progress → In review → Done**

Task priority: **low**, **medium** or **high**.

## Application

| Status | Meaning |
|---|---|
| **Awaiting decision** | The client hasn't answered yet; you can exchange messages about the application |
| **Accepted** | The freelancer was added to the team |
| **Rejected** | The client chose others or closed hiring |

## Submission

**Awaiting review**, **Accepted**, **Returned for revision**.

## Milestone

**Planned → In progress → In review → Completed**. Payment marks: **Not reserved**, **Conditionally reserved**, **Marked as paid** — see [Milestones](./milestones.md).

## Complaint

**Awaiting review**, **Resolved**, **Rejected** — see [How to file a complaint](./complaints.md).

## Account

**Active** or **Blocked**. A blocked user can't sign in; the account data is kept.
