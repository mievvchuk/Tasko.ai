## Ada

**Ada** is an AI assistant who knows your projects, tasks and deadlines. Open her with the **Ada** button in the bottom-right corner or on the [AI assistant](https://taskoai.pp.ua/ai) page. On a project or task page she knows what you are looking at.

What you can ask:

- "Which tasks are urgent this week?"
- "What should I do first today?"
- "Compare the applications for my project."
- "What are the risks in the project and what to do about them?"
- "Split the project into milestones."

You can attach a file to a question, e.g. a specification, so Ada takes it into account.

## Project analysis

On the project page, **AI analysis** opens an assessment: progress, overdue tasks, deadline risks and advice.

## Application ranking

Ada ranks the applications to a project and explains how each candidate fits: budget, timeline, skills, experience.

## AI planning

Project page → **AI planning** (available to the project owner):

1. Ada suggests a draft: **milestones**, **tasks** in each and **acceptance criteria**.
2. Review the draft, change titles, amounts and dates, remove what you don't need.
3. Save — the milestones and tasks appear in the project and on the board.

:::caution Check the answers
AI can make mistakes. Before saving a plan check the amounts and dates, and verify important conclusions against the data on the project page.
:::
