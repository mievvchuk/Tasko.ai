# Дизайн-система Tasko.ai

Усі стилі вебзастосунку зібрано в одному файлі `src/app.css`. Він замінив
чотири старі файли (`styles.css`, `redesign.css`, `palette.css`, `admin.css`),
які перекривали один одного. Назви класів у компонентах не змінювались.

Мета дизайну — щоб людина без пояснень розуміла, де вона і що натиснути:
меню завжди з підписами, один акцентний колір для дій, статуси різних кольорів,
великі поля й кнопки.

## 01 · Кольорові токени

Токени оголошено в `:root`, темна тема перевизначає їх у `:root[data-theme="dark"]`
(атрибут ставить `src/theme.ts`).

| Токен            | Призначення                                | Світла    | Темна     |
| ---------------- | ------------------------------------------ | --------- | --------- |
| `--bg`           | Фон сторінки                               | `#F5F6F8` | `#0F1115` |
| `--surface`      | Картки, панелі, поля                       | `#FFFFFF` | `#171A21` |
| `--surface-2`    | Заголовки таблиць, колонки Kanban, наведення | `#F1F3F6` | `#1F232C` |
| `--line`         | Рамки й розділювачі                        | `#E3E6EB` | `#2A2F3A` |
| `--text`         | Основний текст                             | `#111827` | `#EEF0F4` |
| `--text-2`       | Другорядний текст                          | `#4B5563` | `#B9BFCB` |
| `--text-3`       | Підписи, підказки                          | `#6B7280` | `#8D94A2` |
| `--primary`      | Головні кнопки, активний пункт меню        | `#2563EB` | `#4F86F7` |
| `--success`      | «Завершено», «Прийнято»                    | `#15803D` | `#4ADE80` |
| `--warning`      | «На перевірці», «Пауза», середній пріоритет | `#B45309` | `#FBBF24` |
| `--danger`       | Помилки, прострочене, «Вийти»              | `#B91C1C` | `#F87171` |
| `--violet`       | Усе, що стосується AI-помічниці            | `#6D28D9` | `#B9A2FB` |

Кожен статусний колір має м'яку пару `*-soft` для фону пілюль і сповіщень.

**Кольори статусів:** сірий — ще не почато (TODO, PLANNING), синій — у роботі
(ACTIVE, IN_PROGRESS), жовтий — чекає (REVIEW, PAUSED, PENDING), зелений —
готово (DONE, COMPLETED, ACCEPTED, RESOLVED), червоний — скасовано (CANCELLED, REJECTED).

## 02 · Типографіка

Шрифт **Manrope** (`public/fonts/Manrope-Variable.ttf`), запасні — Segoe UI і системний.

| Рівень  | Розмір | Вага |
| ------- | ------ | ---- |
| H1      | 28 px  | 750  |
| H2      | 18 px  | 700  |
| H3      | 16 px  | 650  |
| Body    | 15 px  | 400  |
| Caption | 13 px  | 400  |

Цифри в таблицях і картках статистики — однакової ширини (`tabular-nums`).

## 03 · Компоненти

- **Кнопки** (`.button`): висота 40 px, радіус 8 px. `.primary` — синя,
  `.secondary` — біла з рамкою, `.ghost` — без фону, `.danger-outline` — червона рамка.
- **Поля:** висота 42 px, підпис над полем, синя обвідка у фокусі, червона рамка
  при `aria-invalid="true"`.
- **Панелі** (`.data-panel`): білий фон, рамка, радіус 14 px; заголовок панелі
  (`.panel-heading`) відділено лінією.
- **Таблиці:** сірий рядок заголовків великими літерами, підсвічування рядка при наведенні.
- **Kanban:** колонки на сірому фоні з кольоровою крапкою статусу, картки білі;
  колонка, куди можна кинути картку, підсвічується синім.
- **Вкладки проєкту** (`.project-links`): горизонтальний ряд з підкресленням.
- **AI-помічниця:** фіолетовий аватар, повідомлення користувача — синя бульбашка праворуч.

## 04 · Навігація

- **Від 901 px:** світла бічна панель 248 px з іконками **і підписами**.
  Активний розділ — синій фон. Тема, мова й акаунт — унизу панелі.
- **До 900 px:** верхня панель з логотипом, акаунтом і кнопкою ☰.
- **До 600 px:** додатково нижня панель (Головна · Проєкти · Повідомлення · Профіль),
  кнопка AI піднімається над нею, панель AI відкривається на весь екран.
- **Адмінка:** та сама бічна панель, на телефоні виїжджає зліва.

## Доступність

- Контраст тексту й кнопок відповідає WCAG 2.1 AA в обох темах.
- Фокус з клавіатури завжди видно (синя обвідка `--focus`).
- Посилання «Перейти до вмісту» з'являється при натисканні Tab.
- `prefers-reduced-motion` вимикає всі анімації.
