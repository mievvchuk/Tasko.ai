## Проєкт

| Статус | Значення |
|---|---|
| **На модерації** | Новий або змінений проєкт чекає на перевірку адміністратора. Бачить лише власник |
| **Відхилено модератором** | Проєкт треба виправити за вказаною причиною й зберегти знову |
| **Пошук виконавця** | Проєкт на біржі, приймає заявки |
| **У процесі** | Команду найнято, триває робота. Поки набір не закрито, проєкт лишається на біржі з позначкою «Добирають команду» |
| **Призупинено** | Роботу тимчасово зупинено |
| **Завершено** | Роботу прийнято, можна залишити відгуки |
| **Скасовано** | Проєкт закрито без результату |

## Завдання

**До виконання → У процесі → На перевірці → Завершено**

Пріоритет завдання: **низький**, **середній** або **високий**.

## Заявка

| Статус | Значення |
|---|---|
| **Очікує рішення** | Клієнт ще не відповів; можна листуватися щодо заявки |
| **Прийнято** | Фрілансера найнято в команду |
| **Відхилено** | Клієнт обрав інших або закрив набір |

## Здача роботи

**Очікує перевірки**, **Прийнято**, **Повернуто на доопрацювання**.

## Етап

**Заплановано → У процесі → На перевірці → Завершено**. Позначки оплати: **Не зарезервовано**, **Умовно зарезервовано**, **Позначено оплаченим** — див. [Етапи](./milestones.md).

## Скарга

**Очікує розгляду**, **Вирішено**, **Відхилено** — див. [Як подати скаргу](./complaints.md).

## Обліковий запис

**Активний** або **Заблокований**. Заблокований користувач не може увійти; дані акаунта зберігаються.
