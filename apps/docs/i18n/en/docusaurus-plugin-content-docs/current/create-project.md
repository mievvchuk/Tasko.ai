## Creating

![The Create project form with a title and description filled in](/img/help/create-project.en.webp)

1. Open **My projects** → **Create project** or go [here](https://taskoai.pp.ua/projects/new).
2. Fill in the form:
   - **Title** — short and to the point: "Ceramics online store on React".
   - **Description** — what needs doing, what already exists, how you will accept the result.
   - **Budget** — from and to, in UAH. Freelancers see it on the marketplace.
   - **Deadline** — when the work must be finished.
   - **Category** and **skills** — freelancers filter the marketplace by them.
3. Click **Save**.

:::tip How to write a good description
Describe the outcome, not the process: "a site with a 50-product catalog, a cart and card payment". Add links to examples you like and a list of what you will provide: texts, logo, access.
:::

## Moderation

An administrator reviews every new project first.

1. After saving, the project is **In moderation**: only you can see it.
2. If everything is fine, the administrator approves it. It becomes **Looking for a freelancer** and appears on the marketplace.
3. If not, it becomes **Rejected by moderator** with a reason. Fix the project and save it — it goes back to moderation.

Changes to an already published project also send it back to moderation.

## AI plan

Not sure how to split the work? On the project page open **AI planning**: Ada suggests milestones, tasks and acceptance criteria from the description. See [Ada the AI assistant](./ai.md).
